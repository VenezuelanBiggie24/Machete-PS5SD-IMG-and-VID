Using this page

Seed

-1 picks a random seed. A run of several images (the count next to Generate) takes the seeds one after the other (seed, seed + 1, …); with -1 each image gets a new seed.

CLIP skip

Which layer of the text encoder the prompt is read from, counted from the end. Auto is what stable-diffusion.cpp does by itself: 1 for SD 1.5 and 2 for SDXL models (Pony and Illustrious too). Some SD 1.5 anime models want 2. The setting shows for the models that read the prompt with CLIP (SD 1.5, SD 2.1, SDXL); FLUX, Wan and the others read it with another encoder. The field says what Auto is for the loaded model. 1 is offered only for SD 1.5: with it an SDXL model makes noise, so the server ignores a 1 for every other model. A preset can set it with clip_skip=2 in its # defaults: line.

Prompt starters

Some models want each prompt to begin the same way: Pony models with score_9, score_8_up, score_7_up, and a negative prompt with score_4, score_5. A preset can carry them in a # prompt: and a # negative: line. While it is loaded, the server puts them before the prompts of every run, from this page and from the API, and the Create tab shows them above the fields. A prompt that starts with them already does not get them twice.

Images that are not kept

With Don't keep on the console a run's images and videos do not go into the gallery. Download what you want to keep on this device; the console deletes them when PS5SD starts again. Keep on the console under the image puts one into the gallery after all.

Gallery

In the viewer, the mouse wheel or two fingers zoom in, a drag moves the picture, and a double click or double tap switches between the whole picture and its pixels one to one. Copy prompt, Copy negative and Copy all copy what made the image; Copy all is the text other tools (AUTOMATIC1111, Civitai) read when it is pasted.

Name gives a file a name and tags. The search finds them, and #night finds the files tagged night; a tag in the viewer does that search. They are kept on the console next to the gallery, not in the file.

Video length and time

Wan makes 4n+1 frames: 33 are 2 seconds at 16 per second, 81 are 5 seconds.

On the console, 33 frames at 832×480 take about 2 minutes 15 seconds with the CausVid LoRA (Models tab, LoRAs) at 4 steps and CFG 1, 81 frames about 8 minutes. Without the LoRA, 33 frames take up to 15 minutes at 20 steps.

Flow shift (Video group) moves the steps between the large shapes and motion (higher) and the details (lower). Auto takes the preset's: 3 for Wan 2.1, 5 for Wan 2.2 TI2V.

A start image for video

Wan 2.2 TI2V 5B (Models tab, Get more) makes a video from a picture: the first frame is the picture, and the prompt says what moves. The size follows the picture's aspect, and the picture is cut to it at the middle. Press Edit on an image of the gallery to start from it.

On the console, 33 frames at 1280×704 take about 16 minutes at 20 steps, at 832×480 about 6. Without a start image this model needs its own size, 1280×704: smaller videos from a prompt alone come out washed out. For video from a prompt alone, Wan 2.1 is faster.

Saved settings

A saved setting is a model with its own size, steps, CFG, sampler and LoRAs. Delete removes only the saved setting, never the model. To make one, set up the Create tab and press Save as preset there.

The settings above are saved with the model. Its own options (VAE, tiling and so on) come along. The list is under Models.

LoRAs

A LoRA adds a style, a character or a look to a model. It works only with models of the family it was made for (SD 1.5, SDXL, FLUX…). Pick them on the Create tab, under Style.

DMD2 (anime) and SDXL-Lightning (photos) make SDXL models fast: CFG 1, 4 to 8 steps, sampler LCM for DMD2 and Euler for Lightning. CausVid does the same for Wan 2.1 1.3B videos: CFG 1, 4 steps. Adding one of them sets these settings; removing it again brings back the ones from before, unless you changed them. With DMD2 an SDXL image takes about 11 s instead of 29. It does not suit every finetune: if the image comes out grey and flat, try CFG 1.5 and 8 steps.

Upscalers

An upscaler (ESRGAN) makes an image larger and sharper: with the Upscale button, or in the hires fix on the Create tab. More of them under Get more, or a .pth file under Upload.

Upscale button

The Upscale button under an image and in the gallery runs this model over the image (4 times as wide and high for most). The result goes into the gallery.

Add by link

A link to a file on huggingface.co, or a Civitai model version (a link that ends in modelVersionId=...). The file goes into the models folder on the console, or the loras folder for a LoRA; a Civitai LoRA goes there by itself.

Upload

Any model file on this computer: your own merge or training, or one from another site. It keeps its file name. A model in several files also needs a preset; the Getting models on page shows how.

Keep this page open until the upload is done.

API key

Apps send it as Authorization: Bearer <key>, A1111 apps as the password of their API login. The HTTP API page has the details and how to reach the console from outside your network.

The console's readings

A PS5 app may not read the temperature, the power or the fan. A payload may: PS5SD brings Marice's ps5-exporter and starts it through the ELF loader (port 9021) when it does not run yet. It keeps running after PS5SD closes, until the console restarts. Without an ELF loader these three stay empty.

The temperature is the hottest of the chip's sensors; the power is the whole chip's (CPU, GPU and memory). The fan shows how hard it is driven, from 0 to 100%; its speed cannot be read. CPU is what PS5SD itself uses of the console's CPUs. GPU busy is the share of the time an image or video is made: the GPU has no reading of its own.
